如何啟用 D1 雲端名單與歷史儲存

            
    
              
  1. 開啟 Cloudflare Dashboard → Storage & Databases → D1 SQL Database，建立名為 anan-geo-admin 的資料庫。
    2. 
              
  2. 進入 Worker anan-geo-public-site → Settings → Bindings，新增 D1 綁定且 Variable name 設為 DB。
    3. 
              
  3. 進入 Settings → Variables and Secrets，確認已新增 Secret 變數 GEO_ADMIN_PASSWORD（可另設 PARTNER_ACCESS_CODE 開放合夥人免費入口、RESEND_API_KEY 與 SERPER_API_KEY 啟用 Google＋地圖找對手加速）。
