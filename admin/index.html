如何啟用 D1 雲端名單與歷史儲存

  1. 開啟 Cloudflare Dashboard → Storage & Databases → D1 SQL Database，建立名為 anan-geo-admin 的資料庫。
  2. 進入 Worker anan-geo-public-site → Settings → Bindings，新增 D1 綁定且 Variable name 設為 DB。
  3. 進入 Settings → Variables and Secrets，確認已新增 Secret 變數 GEO_ADMIN_PASSWORD（可另設 RESEND_API_KEY 與 SERPER_API_KEY 啟用 Google＋地圖找對手加速）。

手機安裝成全螢幕 App（PWA）

standalone

在手機 Chrome 開啟 anangeo.com/admin/，點右上角選單「加到主畫面 / 安裝應用程式」；iPhone Safari 點下方「分享」→「加入主畫面」，桌面圖示點擊即全螢幕開啟。
