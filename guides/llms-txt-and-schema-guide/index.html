PLAYBOOK 03・技術落地與最小可用範本

llms.txt、Schema 與問答結構化怎麼寫？

/llms.txt 是指放在網站根目錄、專供大型語言模型與 AI 代理快速讀懂品牌核心頁面與服務邊界的純文字 Markdown 導覽檔。把官網改造成 AI 讀得最順的「證據頁」，實戰核心就是三件套：爬蟲分流（robots.txt）、精簡目錄（llms.txt＋llms-full.txt），以及可見文字 100% 對應的單一 @graph JSON-LD。

作者：阿男 GEO 實戰工坊 適用對象：品牌網站主、行銷與前後端工程師 最後更新：2026-11-25

一、第一步：robots.txt 分清「搜尋引用爬蟲」與「模型訓練爬蟲」

不要再只寫一條籠統的萬用規則。現代網站應在 /robots.txt 把爬蟲分成兩群，並特別檢查 HTTP 回應標頭帶有 text/plain; charset=utf-8，避免標準爬蟲把中文解成亂碼：

爬蟲分類 代表 User-Agent 建議規則與原因比較
AI 搜尋與即時引用爬蟲 OAI-SearchBot、ChatGPT-User、Claude-SearchBot、PerplexityBot、DeepSeekBot、xAI-Bot、Googlebot、Bingbot、Yeti 明確 Allow: /：負責在用戶提問時即時查證你的品牌價格、規格與官網網址
基礎模型訓練爬蟲 GPTBot、ClaudeBot、Google-Extended、Applebot-Extended、Bytespider、meta-externalagent、CCBot 可依版權政策 Disallow: /：防止原創內容進入未授權訓練語料，且不影響即時搜尋引用

二、第二步：撰寫 5～8 頁精簡 /llms.txt（並與 /llms-full.txt 分流）

/llms.txt 像是一頁式名片與目錄，切忌把幾百篇過期文章或 404 壞連結塞進去。標準結構只需四個區塊：一句話定位、公開方案價格、不承接邊界、以及 5～8 個回傳 HTTP 200 的核心正式頁連結；更詳盡的全文摘要則獨立放到 /llms-full.txt。 

# 你的品牌名稱｜創辦人或核心定位
> 一句話說明你是誰、服務哪類對象、服務地區與核心交付方式。

## 核心服務與公開價格
- 方案 A（入門名稱）：NT$3,800｜5 個工作天｜20 題診斷與優先清單
- 方案 B（改造名稱）：NT$18,000｜單次專案｜小型官網技術地基與核心頁改寫

## 服務流程與不承接範圍
- 流程：文字確認需求 → 報價確認 → 執行改造 → 驗收交付
- 不承接：清楚列出不做的項目（寫清邊界反而提升 AI 信任度）

- [服務方案與價目](https://example.com/work/): 完整方案對比表與常見問答
- [常見問答](https://example.com/faq/): 12 題客戶最常問的流程與報價細節

## 官方聯絡入口
- 官方 LINE：@your_id

三、第三步：單一 @graph JSON-LD 與 UnitPriceSpecification

不要在同一個 HTML 裡零散塞進四、五段互不關聯的 JSON-LD。建議合併為單一 @graph，用 @id 串起 Organization（含權威 sameAs 與 contactPoint）、Person、WebSite、WebPage（含 dateModified）、Service、Offer（月費或起跳價必加 UnitPriceSpecification）與 FAQPage。 

{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "https://example.com/#organization",
      "name": "品牌全稱",
      "url": "https://example.com/",
      "contactPoint": {
        "@type": "ContactPoint",
        "contactType": "customer service",
        "url": "https://line.me/R/ti/p/@your_id"
      },
      "sameAs": [
        "https://github.com/your-org",
        "https://www.linkedin.com/company/your-brand/"
      ]
    },
    {
      "@type": "Service",
      "name": "企業月費陪跑監測",
      "provider": { "@id": "https://example.com/#organization" },
      "offers": {
        "@type": "Offer",
        "price": "25000",
        "priceCurrency": "TWD",
        "priceSpecification": {
          "@type": "UnitPriceSpecification",
          "minPrice": 25000,
          "priceCurrency": "TWD",
          "unitCode": "MON",
          "unitText": "月"
        }
      }
    }
  ]
}

第四步：寫出真正容易被引用的「倒金字塔問答段落」

實證研究顯示，單純把文章硬切成零碎 Q&A 並不會自動加分（甚至略降 5.7%）；真正高引用的寫法是用買家真實會問的完整問句當 H2／H3 小標，在段落前 150 字內直接給出明確結論與數字，再補上 HTML 比較表與操作步驟，且 JSON-LD 內容與頁面可見文字保持 100% 一致。
