隱私權政策｜Privacy Policy

本政策適用於 阿男 GEO 實戰工坊（Anan GEO Workshop） 營運之公開網站（https://anangeo.com）及貼文同步中繼服務（https://relay.anangeo.com），清楚揭露 Meta Threads 授權（threads_basic、threads_content_publish）與 LINE 官方帳號串接之資料處理原則。
This Privacy Policy explains how Anan GEO Workshop (anangeo.com and relay.anangeo.com) collects, uses, protects, and deletes data when store owners connect their Threads accounts via Meta OAuth (threads_basic, threads_content_publish) and our LINE Official Account publishing assistant.

SECTION 01

一、收集哪些資料｜Data Collection

繁體中文

我們僅收集提供「官網與 Threads 同步發布」及「公開網站初檢報告寄送」所必需的最小限度資料：

  • Threads 授權資料（僅於店家本人主動點擊授權時取得）：當店家老闆主動點擊授權連結並於 Meta 官方授權視窗同意後，我們透過 threads_basic 取得您的 Threads 用戶編號（Threads User ID） 與基本公開帳號識別資訊，並透過 threads_content_publish 取得代為發布貼文之授權權杖（Access Token）。
  • LINE 官方帳號傳入之待發圖文與店家設定：店家本人主動於 LINE 聊天室傳送的待發布文案、活動海報或商品圖片、店名、公開官網網址與品牌色票設定，以及用於識別該店家身分的 LINE 用戶識別碼（LINE User ID）。
  • 官網初檢與自願留存信箱：訪客使用首頁免費公開頁檢測並主動勾選同意後所填寫的公開官網網址與接收報告用電子信箱。
  • 明確不收集之資料：我們絕不讀取您的 Threads 私人訊息、不抓取未授權追蹤者名單、不收集支付卡號，也不向任何第三方資料仲介購買個資。
ENGLISH

We strictly follow data minimization and collect only the information required to provide merchant-authorized publishing and website report delivery:

  • Threads OAuth Data (Only Upon Explicit Owner Consent): Only when a store owner actively initiates Threads OAuth and approves Meta's consent screen do we obtain the owner's Threads User ID and basic public profile metadata via threads_basic, together with a publishing access token via threads_content_publish.
  • LINE Publishing Content & Store Configuration: Draft post text, promotional images or posters voluntarily sent by the store owner via our LINE Official Account, along with store name, public website URL, brand palette settings, and the LINE User ID used to bind that owner to their store workspace.
  • Website Check Reports: Public website URLs submitted for basic checks and an email address only when voluntarily entered with explicit opt-in consent to receive the report.
  • What We Never Collect: We do not read direct messages, scrape follower lists, collect payment card numbers, or purchase personal data from data brokers.

SECTION 02

二、資料用途｜Data Usage

繁體中文

所有收集的資料均僅用於執行店家本人明確指示的服務操作：

  • 人工確認後才同步發文：店家在 LINE 傳送素材後，系統會先產生預覽卡片；只有在店家本人親自點擊「確認上架」按鈕後，系統才會呼叫 Threads 官方 API 與店家官網端點，將該筆貼文同步發布至店家自己的官網與 Threads 帳號。
  • 多租戶帳號識別與防誤發：利用 LINE User ID 與 Threads User ID 核對租戶歸屬，確保每位老闆的草稿與權杖完全隔離，絕不跨店混用。
  • 撤銷與刪除回呼處理：於 Meta 觸發取消授權或資料刪除通知時，即時比對 Threads User ID 並自動清除對應權杖。
  • 報告寄送與客服支援：依訪客同意寄出初檢報告，或於店家聯繫官方 LINE 時協助排除設定問題。
ENGLISH

Collected data is used exclusively to carry out actions explicitly instructed by the store owner:

  • Owner-Confirmed Cross-Publishing: After a store owner sends text or images in LINE, our assistant returns an interactive preview card. Only after the owner explicitly taps "Confirm & Publish" does the system publish that post to the owner's own website and authorized Threads account.
  • Strict Multi-Tenant Isolation: LINE User ID and Threads User ID are used strictly to verify workspace ownership so each merchant's drafts and tokens remain isolated.
  • Automated Compliance Callbacks: Threads User IDs are matched solely to execute immediate token revocation and deletion when triggered by Meta's deauthorize or data deletion webhooks.
  • Report Delivery & Support: Sending requested website check reports (opt-in only) and assisting store owners via official support channels.
SECTION 03

三、資料保存安全與零轉售承諾｜Data Storage & Sharing

繁體中文
  • Cloudflare 安全加密基礎設施：所有傳輸全程採用 HTTPS／TLS 加密；店家授權權杖、設定資料與待發圖片皆儲存於 Cloudflare 安全雲端資料庫（D1）與物件儲存空間（R2），並以權限隔離與常數時間驗章機制保護存取。
  • 絕不轉售、出租或交換：我們鄭重承諾，絕不出售、出租、交換或授權任何用戶與店家資料給第三方行銷機構、廣告商或資料仲介。
  • 絕不用於外部模型訓練：店家傳入之圖文素材、帳號資訊與授權紀錄絕不提供或用於任何外部模型訓練。
  • 必要基礎設施與保存期限：僅在提供服務必要範圍內透過 Cloudflare（雲端代管）、Meta Threads API（依店家指令發文）與 LINE Messaging API（傳遞確認卡片）處理資料；當店家解除授權或申請刪除時，授權權杖立即清除，完整資料於確認後 48 小時內（最遲 7 個工作天內）刪除。
ENGLISH
  • Encrypted Storage on Cloudflare: All traffic is encrypted in transit via HTTPS/TLS. Authorization tokens, tenant records, and publishing media are stored securely on Cloudflare D1 and Cloudflare R2 with strict tenant isolation and constant-time cryptographic signature verification.
  • Zero Sale, Rental, or Sharing: We never sell, rent, trade, or transfer user or merchant data to advertisers, data brokers, or unrelated third parties.
  • No External Model Training: Merchant content, profile identifiers, and tokens are never used for external model training.
  • Sub-processors & Retention: Data is transmitted solely to infrastructure strictly required to fulfill user actions—Cloudflare (secure hosting/storage), Meta Threads API (publishing upon confirmation), and LINE Messaging API (preview cards). Tokens are purged immediately upon revocation, and full deletion requests are completed within 48 hours (and no later than 7 business days).

繁體中文

  • 一鍵前往撤銷與資料刪除說明頁：https://anangeo.com/data-deletion/（完整列出 Threads App 即時移除、LINE 聊天室自助解除綁定、以及書面完整清除三種管道）。

ENGLISH

You retain full control over your authorization and data at all times, including the right to access, correct, revoke permissions, and request permanent deletion:

  • Dedicated Data Deletion & Revocation Page: Visit https://anangeo.com/data-deletion/ for step-by-step self-service revocation and deletion instructions.
  • Instant Automated Callback Purge: Removing our app in Threads triggers Meta's signed webhooks (https://relay.anangeo.com/oauth/threads/deauthorize and https://relay.anangeo.com/oauth/threads/data-deletion), which immediately purge your stored tokens and return a deletion confirmation code and status URL.
